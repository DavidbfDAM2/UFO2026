# UFO 2D

Primer joc 2D fet amb Unity (6.3 LTS). 
L'objectiu és recollir tots els PickUps.
Es mostra la puntuació i un petit missatge de victòria en acabar la partida.

## Build WebGL

[Obre el joc a GitHub Pages](https://davidbfdam2.github.io/UFO2026/)

La build és a [`docs/`](docs/) i el fitxer d'entrada és [`docs/index.html`](docs/index.html).

## Estructura del repositori

| Ruta                                                                      | Contingut                          |
| ------------------------------------------------------------------------- | ---------------------------------- |
| [`docs/`](docs/)                                                          | Compilació WebGL                   |
| [`Assets/Scenes/`](Assets/Scenes/)                                        | Escena del joc                     |
| [`Assets/Scripts/`](Assets/Scripts/)                                      | Scripts en C#                      |
| [`Assets/Prefab/`](Assets/Prefab/) i [`Assets/Sprites/`](Assets/Sprites/) | Prefabs i imatges del joc          |
| [`Packages/`](Packages/)                                                  | Dependències de Unity              |
| [`ProjectSettings/`](ProjectSettings/)                                    | Configuració del projecte de Unity |
